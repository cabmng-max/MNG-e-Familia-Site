MNG e-Familia 1.88 — Guide d'installation

Document préparatoire. Téléchargement commercial non ouvert. Version candidate non encore testée sur une installation Windows vierge. L'installateur n'est pas signé numériquement.

Français

  1. Lorsque la distribution sera ouverte, téléchargez l'installateur depuis le site officiel.
  2. Vérifiez l'origine du fichier. Ne désactivez pas les protections Windows pour poursuivre une installation.
  3. Lancez l'installateur et suivez ses instructions.
  4. Ouvrez MNG e-Familia et passez à l'activation.

Avant toute mise à jour, sauvegardez vos données et vos photos.

العربية

  1. عند فتح التوزيع، نزّل ملف التثبيت من الموقع الرسمي.
  2. تحقق من مصدر الملف ولا تعطّل وسائل حماية ويندوز لتثبيته.
  3. شغّل المثبّت واتبع التعليمات.
  4. افتح MNG e-Familia وانتقل إلى التفعيل.

احفظ نسخة احتياطية من بياناتك وصورك قبل أي تحديث.

English

  1. Once distribution opens, download the installer from the official website.
  2. Verify the file source. Do not disable Windows security protections to proceed.
  3. Run the installer and follow the prompts.
  4. Open MNG e-Familia and proceed to activation.

Back up your data and photos before updating.

Türkçe

  1. Dağıtım başladığında yükleyiciyi resmî web sitesinden indirin.
  2. Dosyanın kaynağını doğrulayın. Kurulum için Windows güvenlik korumalarını devre dışı bırakmayın.
  3. Yükleyiciyi çalıştırın ve yönergeleri izleyin.
  4. MNG e-Familia'yı açıp etkinleştirmeye geçin.

Güncellemeden önce verilerinizi ve fotoğraflarınızı yedekleyin.

Español

  1. Cuando comience la distribución, descargue el instalador del sitio oficial.
  2. Compruebe el origen del archivo. No desactive las protecciones de Windows para instalarlo.
  3. Ejecute el instalador y siga las instrucciones.
  4. Abra MNG e-Familia y continúe con la activación.

Haga una copia de seguridad de sus datos y fotos antes de actualizar.
